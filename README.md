# Olawuyi Muhammad Ademola — Portfolio

A responsive, dark-glassmorphism portfolio built with plain HTML, CSS, and JavaScript.

## Run locally
Open `index.html` in a modern browser. No build tools or package installation are required.

## Included
- Responsive navigation and animated reveal effects
- Seven project cards with category filters and supplied live demo links
- Dark/light theme toggle (browser preference is remembered when storage is available)
- Email, WhatsApp, GitHub, and LinkedIn contact links
- Contact enquiry form that opens a prefilled email in the visitor's default email app
- Custom SVG favicon

## Contact form note
The contact form is frontend-only and uses a `mailto:` link. It does not send mail silently or store submissions on a server. For submissions to arrive without the visitor opening an email app, connect a backend endpoint or a form service before publishing.

## Before publishing
- Confirm that every live demo URL is correct and publicly accessible.
- Add repository links where you want to share source code.
- Add a CV download when your CV is ready.
- Replace illustrative project art with real screenshots if available.
- Consider connecting a server-side or form-service endpoint for the contact form.


## Intro loading screen
- A full-screen animated intro appears before the portfolio.
- The progress bar and status text animate while the page loads.
- The loader fades away once the page is ready, with a short minimum display time.
- Respects reduced-motion preferences and works without additional libraries.
